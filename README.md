# PawMatch

Sveriges sociala app för hundägare.

**Repo:** https://github.com/illanghost-99/pawmatch  
**Firebase:** projekt `pawmatch-404e5` · Bundle ID `app.pawmatch`

## Snabbstart
```bash
git clone https://github.com/illanghost-99/pawmatch.git && cd pawmatch
flutter create . --project-name pawmatch --org app.pawmatch --platforms=ios,android
flutter pub get
flutter run
```

Läs **docs/SETUP-CHECKLIST.md** för Firebase, APNs, Supabase och Vercel.

Lägg aldrig `GoogleService-Info.plist` eller APNs `.p8` i git.
