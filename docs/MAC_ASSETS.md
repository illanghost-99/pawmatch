Startsidabild
1. Spara din bild som welcome_dogs.png (helst utan bakgrund).
2. Lägg den i mappen ~/pawmatch/assets/welcome_dogs.png
3. flutter pub get && flutter build ipa

App-ikon
1. Öppna ios/Runner.xcworkspace i Xcode
2. Runner → Assets.xcassets → AppIcon
3. Släpp 1024x1024 PNG i App Store-rutan
